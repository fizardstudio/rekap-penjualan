Kebijakan Privasi

Aplikasi: Rekap Penjualan · Pengembang: Fizard Studio · Berlaku sejak 26 Oktober 2026

1. Ringkasan

Rekap Penjualan adalah aplikasi desktop yang berjalan di komputer pengguna untuk mencatat dan merekap transaksi penjualan. Seluruh data transaksi disimpan di komputer pengguna (folder data di samping aplikasi). Pengembang tidak mengoperasikan server dan tidak menerima, menyimpan, atau melihat data pengguna.

2. Data Google yang diakses

Fitur backup ke Google Drive bersifat opsional dan hanya aktif bila pengguna menekan “Hubungkan Google Drive” dan memberikan izin. Aplikasi meminta izin berikut:

  • https://www.googleapis.com/auth/drive.file — membuat folder “Backup Rekap Penjualan” serta membuat, memperbarui, dan menghapus file backup yang dibuat oleh aplikasi ini sendiri. Aplikasi tidak dapat melihat atau mengubah file lain di Google Drive pengguna.
  • openid dan email — hanya untuk menampilkan alamat email akun yang terhubung di dalam aplikasi.

3. Cara data digunakan

  • File backup (berisi data transaksi dan lampiran milik pengguna) dikirim langsung dari komputer pengguna ke Google Drive pengguna.
  • Token akses Google disimpan hanya di komputer pengguna (file data/gdrive.json) dan tidak disertakan di dalam file backup.
  • Data tidak dijual, tidak dibagikan kepada pihak ketiga, dan tidak dipakai untuk iklan atau melatih model AI.

Penggunaan informasi yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use.

4. Menghapus akses dan data

  • Di aplikasi: Pengaturan → Backup Google Drive → Putuskan. Token dihapus dari komputer dan akses dicabut.
  • Di akun Google: myaccount.google.com/permissions → pilih Rekap Penjualan → hapus akses.
  • File backup dapat dihapus kapan saja dari folder “Backup Rekap Penjualan” di Google Drive.

Privacy Policy (English)

Rekap Penjualan is a desktop application that runs on the user's own computer. All business data is stored locally. The developer (Fizard Studio) operates no server and never receives user data.

The optional Google Drive backup requests drive.file (create and manage only the backup files and folder created by this app), plus openid and email (to display the connected account). Backups are uploaded directly from the user's computer to the user's own Google Drive. OAuth tokens stay on the user's computer and are excluded from backups. Data is not sold, shared with third parties, used for advertising, or used to train AI models. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Users can disconnect in the app (Settings → Google Drive backup → Disconnect) or revoke access at myaccount.google.com/permissions. Contact: firmanmochamad09@gmail.com
