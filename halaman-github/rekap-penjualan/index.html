Rekap Penjualan

Aplikasi desktop untuk mencatat dan merekap transaksi penjualan ke instansi pemerintah dari Digipay, INAPROC (Katalog Elektronik), dan Mbizmarket.

Pencatatan transaksi

Impor surat pesanan PDF, tempel data Digipay, pilih barang dari master, PPN & PPh dihitung otomatis.

Rekap & laporan

Dashboard grafik, rekap per bulan, per satker, dan per CV, serta ekspor ke Excel.

Data tetap di komputer Anda

Aplikasi berjalan di komputer pengguna. Backup opsional ke Google Drive milik pengguna sendiri.

Backup ke Google Drive

Bila pengguna menghubungkan akun Google, aplikasi menyimpan file backup (zip) ke folder “Backup Rekap Penjualan” di Google Drive milik pengguna tersebut. Aplikasi hanya meminta izin drive.file, sehingga hanya dapat mengakses file yang dibuatnya sendiri. Rincian ada di Kebijakan Privasi.
